# AI知识库-拆分-挪动

## 功能
以subagent的形式将inbox目录中的文件移动到临时目录，为后续的拆分和处理做准备。

## 强制约束
生成或修改的md文件，需要以`utf-8`编码保存。

## 操作步骤
1. 检查inbox目录是否存在
2. 检查根目录下的raw/目录是否存在，如果不存在则创建；然后在根目录下的raw/目录下创建目录YYYYMMdd，YYYYMMdd是当前日期的格式。
3. 将inbox中的所有文件移动到根目录下的raw/YYYYMMdd中。
4. 返回移动结果（JSON格式，包含移动的文件列表和状态信息）
5. 触发AI知识库-拆分-读取提炼这个skill，输入为JSON格式的移动结果

## 输入
无特殊输入，自动处理inbox目录

## 输出
JSON格式，包含移动的文件列表和状态信息
